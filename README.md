# Langgraph A2A agent

## Setup 

For local tests install `langgraph-sdk`

Agent card is available at `http://127.0.0.1:2024/.well-known/agent-card.json?assistant_id=TheID`

Upon deployment / running the server, LangGraph automatically creates a default assistant per graph, tied to that.

Agent card can be adjusted in LangGraph Studio / LangSmith UI
